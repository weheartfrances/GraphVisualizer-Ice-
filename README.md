# GraphVisualizer-Ice-


The Graph Algorithms Visualizer is a Java programme that allows users to create graphs and see how different graph algorithms work. A graph is made up of vertices (the circles) and edges (the lines connecting them).
The main purpose of this programme is to make it easier to understand graph algorithms by showing them visually instead of only looking at code.

2. Technologies Used
Java 21: Used to write the programme.
Java Swing and AWT: Used to create the graphical interface.
NetBeans / IntelliJ IDEA: Used to write and run the code. (Change this to the IDE you actually used.)
GitHub: Used to store and manage the project.
Data structures: Maps and lists are used to store and work with vertices and edges.
